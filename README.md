# DC Bench · 纯浏览器直流电阻网络工作台

面向教学实验台的直流稳态求解器：学生把两个矛盾的理想电压源接在一起时，面板会明确指出
**哪条 KVL/KCL 约束无法满足**（并高亮环路上的元件），而不是给出一组 NaN。

技术栈：Svelte 4 + TypeScript（交互）、Konva（原理图）、mathjs（修正节点分析求解）、
IndexedDB（工程持久化，无后端、无网络请求）。

## 运行

```bash

npm run build      # 生产构建
```

## 建模约定

- **接点与地由用户显式放置**：不隐式创造节点；全电路至多一个参考地（地工具在已接地接点上
  再点一次可取消）。没有地时直接报 `no-ground`，不猜测参考点。
- **线交叉不导通**：连接只发生在显式接点（实心圆点）上。两根导线在画面上的交叉处画跨越弧，
  不产生电气连接（`geometry.ts → interiorIntersections` 只用于绘制，不参与拓扑）。
- **极性/方向一致**：每个元件有 `p`、`q` 两端。
  - 电阻：`v = V(p)−V(q)`，`i` 正方向 `p→q`，`i = v/R`；
  - 电压源：约束 `V(p)−V(q) = Vs`，附加支路电流变量，正方向 `p→q`（图上左 `+` 右 `−`）；
  - 电流源：电流从 `p` 流向 `q`（图上箭头 `p→q`）。
  结果表与图上标注全部沿用这一约定；“翻转极性”按钮只是交换 `p`/`q`。
- **拖动不改连接**：连接完全是节点 id 的引用。拖元件体只改元件中心，引脚在画布上拉伸，
  节点引用不变；拖共享接点只改坐标，连在它上面的所有元件/导线一起跟随。只有把端子柄
  明确拖到另一个接点上，才会重绑引用。

## 求解（`src/lib/solver.ts`）

标准修正节点分析（MNA）：导线与 0V 电压源先用并查集合并成“网络(net)”，变量为
非地网络电压 + 每个电压源（同值并联组合并为一个）支路电流。矩阵用 mathjs `lusolve` 求解，
并计算 `‖Ax−b‖∞` 残差。

每行方程都带 **元件来源标注**：电阻/电压源盖章产生的系数记录 `origin`，电流源进入右端时
记录 `rhsOrigins`。右侧“修正节点方程”面板中点击任意系数即可在图上高亮对应元件。

求解前的拓扑/约束检查（硬错误则**不求解、不产生 NaN**，工程原样保留且可继续编辑）：

| 检查 | 说明 |
| --- | --- |
| `voltage-conflict` | 仅由理想电压源构成的环，沿环电压升代数和 ≠ 0（如 5V 与 3V 直接并联）。生成森林 + 基本回路算出真实的 ΣV，报告 `沿环 Σ V_k = 0，实际 Σ = …`；另含电压源被导线短接的自环 `0 = Vs` |
| `current-conflict` | 电流源割集矛盾：删去电流源后，R+V 连通块边界上电流源注入代数和 ≠ 0（异值理想电流源串联） |
| `floating-subnet` | 不含地的电气连通块，整体电位自由，矩阵奇异 |
| `isolated-node` | 未接任何元件且不是地的接点，KCL 为 `0=0`、电位自由 |
| `zero-resistance` | R=0（电导无界，提示改用导线）或 R<0（本台只处理正电阻） |
| `no-ground` / `dangling` | 无参考地；元件或导线有悬空端（警告，该元件排除出分析，其余照解） |

同值理想电压源并联：节点电压与并联组总电流唯一、组内电流不唯一——工具合并电流变量给出
数值解，并以警告说明各源电流按均分显示。

求解成功时给出：各节点对地电压、每个元件的 `v / i / P吸收`、电阻总消耗、电源总供出与
**功率失配**（Tellegen 校验），以及 KCL 残差。

## 教学验证

内置示例（顶栏一键载入，对应 vitest 用例）：

1. **惠斯通电桥**：非平衡桥，核对 b、c 节点 KCL、桥臂电流与功率平衡；平衡桥桥臂电流为 0。
2. **串联电源**：5V 与 3V 同向串联得 8V/8Ω = 1A，反极性按代数和；功率平衡。
3. **矛盾电压源（5V∥3V）**：核心反面案例——报 KVL 环约束、高亮 V5、V3，结果区无 NaN。
4. **串联异值电流源（1A/2A）**：报割集 KCL 矛盾。

所有编辑自动防抖存入 IndexedDB（`dc-bench/projects`，按 `updatedAt` 恢复最近工程）。
